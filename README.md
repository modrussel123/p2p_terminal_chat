# P2P Terminal Chat

A peer-to-peer, end-to-end encrypted terminal chat app built in Python.

See [p2p_chat/README.md](p2p_chat/README.md) for full documentation, installation, and usage instructions.

## Quick Start

```bash
cd p2p_chat
pip install -r requirements.txt
python main.py
```

Choose to host or join a chat session.
